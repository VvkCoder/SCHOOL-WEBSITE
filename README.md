# 🏫 Sunrise International High School

A full-stack school website built with React.js and Node.js.

## Features
- Responsive Navbar with smooth scrolling
- Hero section with Apply Now modal
- Find a Campus modal
- About section with stats
- Courses section
- Contact form with real email sending
- Admission enquiry form
- Footer with quick links

## Tech Stack
- Frontend: React.js, CSS
- Backend: Node.js, Express.js
- Email: Nodemailer
- Build Tool: Vite
